- **ccaas packaging's root cause is a Docker BuildKit incompatibility, not just a preference.** `chaincode/certificate-cc/main.go`'s and `chaincode/institution-cc/main.go`'s header comments state plainly: Fabric 2.5.0's bundled Docker client (used by the peer's classic "golang" builder) predates the BuildKit API this host's Docker Engine requires, "forcing this migration earlier than `ARCHITECTURE.md` originally planned." This is a stronger, more specific claim than "ccaas was chosen over classic packaging" (already stated below) — it was never a viable alternative on this host, not a stylistic choice.
